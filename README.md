# timhur.com

Personal website for Tim Hur. Plain HTML, no build step.

- `index.html` — the page
- `images/` — headshot and certificate scans (Tim's own photos)
- `robots.txt`, `sitemap.xml` — for search engines

Hosting: Netlify, auto-deploys from the `main` branch.
DNS: GoDaddy (A @ → 75.2.60.5, CNAME www → Netlify). Email MX records point to Google — leave them alone.
